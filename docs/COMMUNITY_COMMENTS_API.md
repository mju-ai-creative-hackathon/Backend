# 커뮤니티 댓글 API

게시물 상세 화면에서 댓글을 조회하고, 로그인한 사용자가 댓글을 작성할 수 있습니다. 수정과 삭제는 해당 댓글을 작성한 사용자만 할 수 있습니다.

## 댓글 목록

`GET /api/community/posts/{postId}/comments?page=0&size=20`

로그인 없이 조회할 수 있습니다. `page`는 0부터 시작하며 `size`는 1~50입니다. 기본값은 `page=0`, `size=20`입니다. 댓글은 작성 시각이 오래된 순으로 표시하며 동일 시각에는 ID를 기준으로 순서를 정합니다.

```json
{
  "content": [
    {
      "id": "19fa25ec-6b58-4811-98da-aad49d111111",
      "postId": "65ba98cd-e843-4a91-b5ee-7a01aa222222",
      "content": "영상 분위기가 좋아요! 이 코스로 가보고 싶어요.",
      "author": {
        "id": "dc918fea-7daf-4a47-b463-231aab333333",
        "name": "서울 산책자",
        "profileImageUrl": null
      },
      "createdAt": "2026-11-06T04:00:00Z",
      "updatedAt": "2026-11-06T04:00:00Z"
    }
  ],
  "page": 0,
  "size": 20,
  "totalElements": 1,
  "hasNext": false
}
```

댓글이 없는 게시물은 `200`과 빈 `content` 배열을 반환합니다. 게시물이 삭제되었거나 게시물 작성자가 탈퇴하여 게시물을 볼 수 없으면 `404`입니다. 탈퇴한 댓글 작성자의 댓글은 표시하지 않습니다.

## 댓글 작성

`POST /api/community/posts/{postId}/comments`

`Authorization: Bearer <accessToken>`과 `Content-Type: application/json`이 필요합니다.

```json
{
  "content": "어느 시간대에 방문하셨나요?"
}
```

- `content`: 필수 문자열, 최대 1,000자. 공백만 입력할 수 없습니다.
- 작성자 ID나 이름은 전송하지 않습니다. 인증된 사용자 정보를 사용합니다.
- 성공하면 `201`과 생성한 댓글 정보를 반환합니다. 응답 형식은 목록의 댓글 항목과 같습니다.

## 댓글 수정

`PATCH /api/community/posts/{postId}/comments/{commentId}`

댓글 작성자의 인증 토큰과 새 `content`를 전송합니다.

```json
{
  "content": "방문 시간과 코스 공유 감사합니다!"
}
```

성공하면 `200`과 수정한 댓글 정보를 반환합니다. `createdAt`은 유지하고 `updatedAt`은 갱신합니다. 입력 조건은 댓글 작성과 같습니다.

## 댓글 삭제

`DELETE /api/community/posts/{postId}/comments/{commentId}`

댓글 작성자의 인증 토큰이 필요하며 성공하면 본문 없는 `204`를 반환합니다. 게시물 작성자라는 이유로 다른 사용자의 댓글을 수정하거나 삭제할 수는 없습니다.

게시물을 삭제하면 연결된 댓글도 삭제합니다. 회원 탈퇴 시 해당 사용자가 작성한 댓글도 삭제합니다.

## 프론트 연결

1. 게시물 상세 화면을 열 때 첫 페이지를 조회합니다.
2. `hasNext`가 `true`이면 `page`를 1씩 늘려 다음 페이지를 조회합니다.
3. 로그인한 사용자가 작성하면 댓글 목록을 갱신합니다. 오래된 순 목록이므로 새 댓글은 마지막 페이지에 위치할 수 있습니다.
4. 로그인 사용자 ID와 `author.id`가 같을 때 수정·삭제 메뉴를 표시합니다. 최종 권한 검사는 서버에서 수행합니다.
5. 수정·삭제 후 목록을 다시 조회합니다. 페이지 조회 사이에 댓글이 추가·삭제될 수 있으므로 필요하면 목록을 새로고침합니다.

댓글은 일반 텍스트입니다. 앱이나 웹에서 HTML로 해석하지 말고 텍스트로 표시합니다. 줄바꿈은 화면 정책에 맞게 표시할 수 있습니다. 이 API에는 대댓글, 댓글 좋아요, 알림 기능이 포함되어 있지 않습니다.

## 오류

| HTTP 상태 | 상황 |
| --- | --- |
| `400` | 빈 내용·공백만 있는 내용·길이 초과·잘못된 페이지 값이나 ID 형식 |
| `401` | 작성·수정·삭제 요청에 유효한 인증 토큰이 없음 |
| `404` | 게시물이나 댓글이 없거나 접근할 수 없음, 다른 게시물의 댓글 ID, 다른 사용자의 댓글 수정·삭제 |

오류 응답은 기존 공통 형식인 `code`, `message`, `errors`, `timestamp`를 사용합니다.
